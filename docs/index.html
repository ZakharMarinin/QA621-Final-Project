Одно приложение на Python, тесты к нему — и защита на экзамене.

Ниже — два варианта экзаменационного проекта. Выберите один, напишите консольное приложение с полноценным ООП и работой с файлами, покройте его тестами на pytest и сдайте через pull request в репозиторий курса.

Магазин

Каталог, корзина, промокоды и заказы в терминале

Товары трёх типов по-разному считают стоимость, промокоды — скидку. Оформление заказа списывает остатки, отмена возвращает. А тесты доказывают, что касса не ошибается ни на копейку.

Открыть задание
3 типа товаров, 3 типа промокодов, склад в JSON, от 15 тестов

Валидатор

Проверка тестовых данных по правилам из конфига

QA-инструмент: берёт CSV или JSON с тестовыми данными, прогоняет каждую запись по правилам из rules.json и выдаёт отчёт о нарушениях — в консоль, CSV, JSON или Markdown.

Открыть задание
7 правил, 4 формата отчёта, коды выхода для CI, от 20 тестов

Оба задания сдаются одинаково — fork, ветка, коммиты, pull request. PR — до 21 октября, защита — 22 октября 2026.
