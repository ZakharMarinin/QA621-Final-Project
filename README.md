# QA621 — экзаменационный проект

Репозиторий курса с заданиями экзаменационного проекта. Два независимых
варианта — студент выбирает один, реализует консольное приложение на Python
с полноценным ООП, работой с файлами (JSON/CSV) и **обязательным набором
автотестов на pytest**, сдаёт через pull request и защищает на экзамене.

**Дедлайн: pull request открыт не позже 21 октября 2026 года, 23:59.**
Изменения после дедлайна не учитываются, если не указано иное.

**Защита: 22 октября 2026 года** (занятия 37–38) — около 10 минут на
человека: демонстрация в терминале, прогон `pytest -v`, вопросы по коду.

## Задания

| Проект | Что это | ТЗ |
|---|---|---|
| **Магазин** | Каталог, корзина, промокоды и заказы в терминале + тесты на pytest | [`variants/ТЗ 1 CLI_SHOP.md`](variants/ТЗ%201%20CLI_SHOP.md) |
| **Валидатор** | QA-инструмент: проверка тестовых данных (CSV/JSON) по правилам из JSON-конфига + тесты на pytest | [`variants/ТЗ 2 CLI_VALIDATOR.md`](variants/ТЗ%202%20CLI_VALIDATOR.md) |

Оба ТЗ построены на материале занятий 1–30: ООП (все 4 принципа по
существу, `abc`, `@property`), дандер-методы и `dataclasses`, файлы
JSON/CSV, собственные исключения, декораторы, модули и пакеты, pytest с
фикстурами, `conftest.py` и `tmp_path`. Подробности — в самих файлах.

## Сайт

Оформленные версии обоих ТЗ и инструкция по сдаче опубликованы как
небольшой статический сайт: `docs/index.html`. После включения GitHub Pages
(Settings → Pages → Source: Deploy from a branch → Branch `main` → `/docs`)
он будет доступен по адресу
`https://zakharmarinin.github.io/QA621-Final-Project/`.

## Структура репозитория

```
variants/    исходные ТЗ (markdown)
docs/        сайт с заданиями и инструкцией по сдаче (публикуется на Pages)
students/    сюда попадают папки со сдаваемыми проектами студентов (через PR)
```

Каждый студент работает только в своей папке
`students/<фамилия_имя>/` (латиницей, например `students/ivanov_ivan/`):

```
students/ivanov_ivan/
├── main.py
├── <пакет проекта>/
├── data/
├── tests/
│   └── conftest.py
├── pytest.ini
├── requirements.txt
└── README.md
```

## Как сдать проект

Коротко: fork этого репозитория → отдельная ветка → регулярные коммиты в
папку `students/<фамилия_имя>/` → `pytest` проходит → pull request сюда с
заголовком `Фамилия Имя — Магазин` или `Фамилия Имя — Валидатор`.
Подробная пошаговая инструкция — на странице «Как сдавать работу» сайта
(`docs/submission.html`) или в разделе 13 каждого ТЗ.
